# Optimum

Optimum is a mathematical optimization platform for smarter business decisions. This repository contains the **Finance MVP** — a web application that helps users build an optimized investment portfolio using mathematical optimization.

## Tech Stack

- **Frontend:** React
- **Backend:** Node.js / Express
- **Database:** MySQL
- **Charts:** Recharts
- **Optimization:** HiGHS (`highs-js`)
- **Authentication:** Login / Registration
- **Version Control:** Git / GitHub

## Main Features

- User registration and login
- Create and manage projects
- Add assets and budget
- Set investment limits and constraints
- Run portfolio optimization
- View recommended allocation
- View expected return and charts
- Save and review previous results
- Admin user management

## How It Works

1. Create a project
2. Add assets, budget, and limits
3. Set the investment goal
4. Run the optimization
5. View the recommended portfolio

Optimum uses mathematical optimization to calculate the best allocation based on the user's data and constraints.

## MVP

The MVP focuses only on **Finance portfolio optimization**. Logistics, Machine Learning, and Engineering Design are future directions.
